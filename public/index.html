saulera dossier engine

This is the deployment shell for the submission dossier engine. It is behind Cloudflare Access, so if you are reading this you came through the front door.

There is no product surface here yet. The only thing that answers is POST /api/health, which reports whether the model key is bound server-side. The recruiter screen, the generation route and the client note are separate tickets.

Every colour, size and radius on this page comes from /tokens.css. An agency's branding is an override of that file, never a fork of this one.
